# CNCF Technical Oversight Committee (github.com/cncf/toc)

The CNCF TOC is the technical governing body of the CNCF. Its responsibilities include: defining and maintaining the technical vision and principles for the Cloud Native Computing Foundation; approving new projects within the scope of the CNCF set by the Governing Board; creating a conceptual architecture for the projects, aligning projects, removing or archiving projects; accepting feedback from the end user technical advisory board and mapping it to projects; aligning interfaces to components under management and establishing common practices across projects.

## Technical Advisory Groups (TAGs) — active as of this snapshot
TAG Developer Experience; TAG Infrastructure; TAG Operational Resilience; TAG Security and Compliance; TAG Workloads Foundation. (The TAGs were restructured in 2025 from the earlier set: App Delivery, Contributor Strategy, Environmental Sustainability, Network, Observability, Runtime, Security, Storage.)

## Project maturity
Projects enter the CNCF at the Sandbox level and may progress to Incubating and Graduated as they meet the criteria in the project lifecycle documentation (adoption, governance, security practices, contributor diversity). The CNCF provides services to projects at each level, with the broadest support for incubating and graduated projects.
