# CNCF — Who we are (cncf.io/about/who-we-are/)

CNCF's mission is to make cloud native computing ubiquitous. The Cloud Native Computing Foundation is part of the nonprofit Linux Foundation. CNCF hosts critical components of global technology infrastructure, including open source projects like Kubernetes, Prometheus, and Envoy — 227 projects at the time of this snapshot across the Graduated, Incubating, Sandbox, and Archived categories.

## How it works
- Governing Board — responsible for marketing, business oversight, and budget decisions.
- Technical Oversight Committee (TOC) — defines the technical vision and provides technical leadership.
- End User Technical Advisory Board — represents end users in community decisions.
- Community groups — 156K+ cloud native community members participate globally; 329K+ CNCF project contributors; 715 CNCF members.

## Events and certifications
CNCF runs KubeCon + CloudNativeCon, its flagship conference series (next: Shanghai, September 7–9, 2026 at time of snapshot). CNCF offers certifications including the Kubernetes certifications (KCNA, KCSA, CKA, CKAD, CKS) and the Cloud Native Network Function (CNF) Certification.
