# Linux Foundation / CNCF cloud native certification catalog (training.linuxfoundation.org/certification-catalog/)

Beginner (associate) level: KCNA — Kubernetes and Cloud Native Associate, foundational knowledge and skills in Kubernetes and the wider cloud native ecosystem; KCSA — Kubernetes and Cloud Native Security Associate; CNPA — Certified Cloud Native Platform Engineering Associate; CBA — Certified Backstage Associate; PCA — Prometheus Certified Associate; OTCA — OpenTelemetry Certified Associate; CGOA — Certified GitOps Associate; CAPA — Certified Argo Project Associate; CCA — Cilium Certified Associate; KCA — Kyverno Certified Associate.

Intermediate (performance-based) level: CKA — Certified Kubernetes Administrator; CKAD — Certified Kubernetes Application Developer; CKS — Certified Kubernetes Security Specialist (requires an active CKA); CNPE — Certified Cloud Native Platform Engineer; ICA — Istio Certified Associate.

The associate exams are multiple choice; the CKA/CKAD/CKS exams are hands-on, performance-based exams in a live terminal.
