# LFS250 — Kubernetes and Cloud Native Essentials (training.linuxfoundation.org)

This course provides an overview of cloud native technologies and how container orchestration systems like Kubernetes can help to implement and maintain them. It is the course bundled with the KCNA exam ("exam + LFS250"). The course delivers an overview of cloud native technologies, and then dives into container orchestration: Kubernetes architecture at a high level, the challenges of container orchestration, and how to deploy and observe applications in distributed environments, contrasting container orchestration with conventional infrastructure approaches.

## Course outline
1. Course Introduction
2. Cloud Native Architecture
3. Container Orchestration
4. Kubernetes Fundamentals
5. Working with Kubernetes
6. Cloud Native Application Delivery
7. Cloud Native Observability
