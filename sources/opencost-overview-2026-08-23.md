# OpenCost (opencost.io/docs/)

OpenCost is a vendor-neutral open source project for measuring and allocating cloud infrastructure and container costs. It's built for Kubernetes cost monitoring to power real-time cost monitoring, showback, and chargeback. OpenCost allocates cost to Kubernetes constructs — namespaces, deployments, pods, labels — and relates them to the underlying cloud costs, exposing the data through an API, a UI, and Prometheus metrics. OpenCost was created by Kubecost and is a CNCF project aligned with the FinOps practice of bringing financial accountability to cloud spending.
